## Tasks

### Task 1: Recent Advancements in Biotechnology — Stem Cell Therapy

A comprehensive review report examining the current state of stem cell therapy, covering:
- Global cell therapy clinical trial landscape (10,373+ trials)
- Pluripotent stem cell-derived therapies (iPSCs, ESCs)
- BioVAT-HF trial — iPSC-derived cardiac tissue for heart failure
- Stem cells in autoimmune and inflammatory disease
- Challenges: immune rejection, tumorigenicity, manufacturing scale

### Task 4: Integrated ML Framework for Biomolecule Design and Bioprocess Monitoring

A mini project proposal outlining a computational framework with three modules:
1. **Generative sequence design** — Conditional autoencoder for RNA aptamer evolution
2. **In-silico mutagenesis** — Protein language model for CRISPR-Cas engineering
3. **Spectral quality prediction** — 1D-CNN for real-time bioprocess monitoring
